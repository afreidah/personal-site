I'm a senior infrastructure engineer with 15+ years designing, automating, and operating production systems across cloud and bare-metal. Most of my work is in the HashiCorp stack (Nomad, Consul, Vault), Terraform and Terragrunt, and Go services: certificate automation, database tooling, admission control, and Temporal-driven workflows. I currently work on infrastructure at Commerce.

I have extensive experience with infrastructure as code and configuration management, automating everything up to dynamic multi-node, multi-region clusters. After using Chef, Puppet, and Ansible professionally, I refuse to let go of Chef. I won't go on a huge rant about why, other than to say that building shared dynamic resources that use custom Ruby libraries for complex logic is a joy, while Ansible just feels like Bash+magic and makes me sad to write, and Puppet feels like Ruby had a stroke. Sadly Opscode sold out, so I use [Cinc](https://cinc.sh/) (Cinc Is Not Chef) now. The Cinc folks are doing god's work keeping the tool alive, and I encourage others to use it too.

Outside of work I run Munchbox, a homelab cluster on Nomad, Consul, and Vault spanning bare-metal nodes, Proxmox VMs, and Oracle Cloud free-tier instances linked over WireGuard, all provisioned as code. Most of the projects below started as something that cluster needed, and this site is served from it.

Before infrastructure I studied classical guitar at the Peabody Conservatory, and I've taught music and guitar for fifteen years, including as faculty at Northern Virginia Community College.
